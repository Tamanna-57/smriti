### Bugs found and fixed
- `e99a0f0` **Seed script crashed on Linux**: `require('./models/Patient')` vs file
  `models/patient.js`. Demo data could not be created on Render/Linux.
- `05d7381` **Wrong PIN still opened the patient dashboard**: on a 401 the app fell
  back to an offline demo session for any name containing "Ramesh"/"Meera".
  Offline fallback now only runs when the server is unreachable.
- `be957a0` **Daily Routine Sequencer showed "0 cards to place"**: the first round
  was never dealt when the start-up effect re-ran (React StrictMode / data refresh).
- `40107ef` **WhatsApp "Done" replies were not recorded for demo patients**: seeded
  phone numbers had spaces, so the webhook could not find the patient; login by
  phone failed for the same reason.
- `df1ca46` **Hindi mode showed the breakfast title on every reminder**: a lookup
  clause ignored the candidate and always returned the first entry.
- `a6bc4d1` **Login rate limit locked out all visitors**: behind Render's
  proxy every visitor shared one counter, and successful logins counted. Now
  only failed attempts count, per real client IP (`trust proxy`).
